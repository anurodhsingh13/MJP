# Dataset attribution

TerraScope uses only these public sources for crop health monitoring with NDVI and satellite imagery.

- **Sentinel-2 Level-2A** (Copernicus programme, ESA), accessed through Google Earth Engine: red (B4) and near-infrared (B8) bands and the SCL scene-classification layer for NDVI and cloud/shadow masking. Contains modified Copernicus Sentinel data.
- **NASA POWER** daily meteorology: historical weather context. https://power.larc.nasa.gov/
- **Open-Meteo** forecast: seven-day weather context. https://open-meteo.com/
- **FAO Crop Calendar**: reference crop-stage timing, loaded from a permission-reviewed manual CSV only.

Check each provider's licence and attribution rules before publishing results.
