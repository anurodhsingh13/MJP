# Reference photographs

Local copies for reliable demo rendering. These are stock references, not photographs of the fictional parcels.

Original source and credit links are retained in `frontend/src/lib/cropPhotos.ts` and the image gallery. Wheat, rice, paddy, harvest, maize and potato photographs are from Unsplash. The satellite reference is credited to the Hungarian meteorological service (met.hu). Downloaded 17 October 2026. No generated images are used.
