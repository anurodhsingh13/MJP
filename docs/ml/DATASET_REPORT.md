## Consequences for the brief

* **Four severity classes cannot be trained.** The labels are cause categories from a survey, not severity. The tasks that can honestly be run are Healthy vs Problem, Healthy / Pests / Diseased / Stressed, and Pests / Diseased / Stressed among problem fields.
* **Labels are one value per field per season, with no date.** A model cannot learn when stress started, and the labels are survey answers that were not independently verified.
* **About 99% of fields were sown in 2023** ({'2023': 3599, '2024': 45}), so year-held-out validation is impossible. Season-held-out (Rabi to Kharif and back) and district-held-out are the available tests.
* **Not extracted from Earth Engine:** B2, B3, B6, B7, B8A, B12, so **NDWI and EVI cannot be computed**, and soil moisture has no source in the repository. Only NDVI, NDRE (B8/B5) and NDMI (B8/B11) exist, cloud-masked with SCL classes 0,1,2,3,8,9,10,11. Rebuilding the extract for 3,644 fields is possible but not done here.
* **Licence:** CC-BY-SA 4.0. The register records that the owner accepts share-alike but has not stated whether a model trained on it may ship in the app, so it is used for evaluation only and no trained weights are shipped or committed (weights stay under `.local/models`).

## Other public data

No further public dataset with dated, agronomist-confirmed crop-stress labels and severity has been verified for this project, so none is named here and nothing was downloaded. What is missing is listed in `docs/ml/PRODUCTION_READINESS.md`.
